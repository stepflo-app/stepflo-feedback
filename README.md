# stepflo-feedback

Public feedback, bug reports, and feature requests for [Stepflo](https://stepflo.ai) — the local-first console for your AI work.

## File a bug or a feature request

Open an **Issue** and pick a template. Both templates end with a required "safe to share" confirmation — this repo is public, and posting here is your choice.

## Ask a question or see what's planned

**Discussions**: *Ideas* (what's being considered), *Q&A* (questions), *Show and tell*.

## What happens next

Everything here is triaged weekly. Status labels track each item:

- `considering` — heard, thinking about it
- `planned` — on the roadmap
- `shipped` — done
- `declined` — not right now

**Trust note:** Stepflo is local-first. Nothing about your machine leaves it unless you choose to send it — and posting here is exactly that choice.
